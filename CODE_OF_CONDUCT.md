# Code of conduct

Vibeless is a small hobby project about keeping a game playable and moddable. Keep it a friendly
place.

## Be kind

- Be patient and helpful, especially with people new to hosting servers, modding or programming.
- Assume good intent. Disagree with ideas, not with people.
- Write so that others can follow you: plain words and no gatekeeping.
- Respect people's time and privacy.

## Not okay

- Harassment, insults, threats, slurs or personal attacks.
- Sexual content, or attention someone has not asked for.
- Sharing someone's private information without their permission.
- Asking for or sharing game files, pirated copies, or other people's keys and accounts.
- Spam, trolling and deliberately derailing a conversation.

## Where this applies

In this repository's issues, pull requests, discussions and commit messages, and anywhere else you
represent the project.

## Enforcement

The maintainer, [Kayatwo](https://github.com/Kayatwo), may edit, hide or remove content, lock
conversations and block people who do not follow this code. Report problems privately to the
maintainer through GitHub, or with a private vulnerability report if it is urgent.

This code is adapted from the one used by [Dauntless Revived](https://github.com/mixutin/dauntless-revived).
